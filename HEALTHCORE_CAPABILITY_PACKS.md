# OPES HealthCore — Eight Composable Industry Capability Packs

OPES HealthCore is architected as **8 composable Industry Capability Packs** built from independently installable Spring Boot 4 starters—NOT eight separate monoliths. Every pack carries a full **16+ field machine-readable manifest** (`META-INF/healthcore/pack-manifest.json`), a dedicated portable Liquibase master changelog (`PostgreSQL 16+` / `MSSQL 2022+` / `MySQL 8.4+`), and transitive isolation verification via `CapabilityPackIsolationTest`.

## Composing Individual Starters Without a Full Pack
Any developer may import `healthcore-bom` and install a single starter directly (Mode A) or combine a minimal subset (Mode C) without pulling unrelated modules. Examples `life-sciences-lims`, `biobank`, `clinical-research`, `diagnostic-laboratory`, and `radiology-center` explicitly demonstrate Mode A/Mode C minimal composition with self-contained portable Liquibase master changelogs.
