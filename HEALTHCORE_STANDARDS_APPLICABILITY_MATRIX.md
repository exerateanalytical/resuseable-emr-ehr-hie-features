# OPES HealthCore — Standards Applicability & 5-Stage Verification Matrix

> **Honesty & Compliance Notice**: OPES HealthCore provides *technical software capabilities* aligned with the standards below. Software alone does **not** confer ISO accreditation, GMP compliance, GCP certification, or regulatory approval. Operating organizations remain solely responsible for institutional QMS, SOPs, computer-system validation (IQ/OQ/PQ), clinical safety governance, and accredited third-party assessment.

## 5-Stage Standards Verification Scale (Directive Section 9)
1. **Standard Identified** — Applicable scope and packs mapped.
2. **Implementation in Progress** — Partial schema or service stubs only.
3. **Technical Implementation Complete** — Domain entities, workflow enforcement gates, Liquibase migrations, and automated unit/contract tests implemented and statically verified in repository.
4. **Automated Conformance Evidence Available** — Executed in external JDK 25 + Maven + Testcontainers / FHIR Validator CI pipeline with archived reports.
5. **Independently Validated / Certified** — Audited by an accredited third-party body on a specific deployed production organization.
