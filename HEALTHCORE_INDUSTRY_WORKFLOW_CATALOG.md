# OPES HealthCore — Industry Workflow Catalog

| Industry Pack | Core End-to-End Workflows Implemented | Mandatory Safety / Governance Controls Enforced in Code |
|---|---|---|
| **PACK 01: Standalone Pharmacy** | Product catalog -> Supplier PO goods receipt -> GS1/expiry validation -> FEFO prescription dispense -> Controlled-substance witnessing -> Recall quarantine -> Near-expiry alerts | Rejects expired goods receipt; enforces FEFO lot ordering; blocks controlled-drug dispense without distinct witness (`SecurityException`); recall automatically removes lot from FEFO eligibility |
| **PACK 02: Diagnostic Centers** | Referring partner intake -> Modality-neutral order accessioning -> Specimen rejection & recollection -> Analytical/imaging execution -> TAT SLA verification -> ISO 15189 incident/CAPA | Mandatory rejection reason; blocks release of `REJECTED_RECOLLECT` orders; flags `tatBreached` automatically against `tatSlaMinutes`; isolates lab-only vs radiology-only deployments |
| **PACK 03: Pharma Manufacturing & QMS** | Product master -> Maker-checker Master Formula approval -> eBMR creation -> Line clearance -> Dual-witness weighing -> IPC -> Yield reconciliation -> QC OOS check & CoA -> QA e-signature batch release -> GS1 commissioning & SSCC aggregation -> Cold-chain monitoring -> Recall stop | Blocks self-approval (`SecurityException`); blocks dispensing before line clearance; blocks QA release on unverified/OOS batches; blocks warehouse dispatch on `QUARANTINE`, `EXCURSION_HOLD`, or `RECALLED` lots; requires effectiveness verification on `CRITICAL` CAPA closure |
| **PACK 04: Life Sciences & Research** | Study creation -> Ethics/IRB approval -> Non-patient scientific sample intake & custody transfer -> Versioned ELN sign-off -> Biobank consent intake, aliquot genealogy, freezer excursion quarantine, MTA release -> Sequencing Q30 QC & VCF catalog -> Trial eConsent, eCRF query lock, SAE expedited flagging, CDISC SDTM export | Blocks sample intake prior to Ethics/IRB approval; locks signed ELN against mutation; blocks biobank intake without consent & cascades donor consent withdrawal to block MTA shipments; blocks genomics datasets from `Q30 < 80%` runs; blocks eCRF lock while open queries > 0 |
| **PACK 05: Outpatient EMR** | MPI registration -> Scheduling & check-in -> Vitals & SOAP encounter -> Allergy/CDSS checks -> Outpatient CPOE & results review -> Signed immutable encounter note & addenda | Immutable signed clinical notes; facility-scoped tenant isolation; break-glass emergency override logging |
| **PACK 06: Longitudinal EHR** | Cross-facility MPI matching -> Longitudinal timeline reconciliation -> FHIR R4 `$summary` / IPS export -> Patient portal consent-scoped self-service -> Clinical templates | Patient-scoped portal claims (`PortalScope`); cross-facility `@ClinicalAudit` provenance logging |
| **PACK 07: Composable HIS** | ED triage -> ADT admission/bed transfer -> Nursing eMAR -> Lab/Radiology/Surgery/Blood Bank -> Discharge -> ICD/CPT coding, UHC/CBHI claims & double-entry ledger | Dual-verification blood crossmatch; WHO surgical safety checklist; double-entry accounting invariants; immutable billing ledger |
| **PACK 08: Regional / National HIE** | EMPI probabilistic/deterministic matching -> FHIR R4 / HL7 v2 / IHE XDS.b/PIX/PDQ routing -> Integration Ops DLQ capture & idempotent replay -> API product keys & rate limiting | Idempotency enforcement; Bucket4j rate limits; HMAC webhook signing; tamper-evident cross-facility audit log |
