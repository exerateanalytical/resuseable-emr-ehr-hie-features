# `healthcore-pack-pharmacy` (Capability Pack 01)

Composable industry pack for independent community pharmacies, pharmacy chains, and e-pharmacy APIs.

- **Included Modules**: `healthcore-persistence-core`, `healthcore-security-audit`, `healthcore-starter-terminology-cdss`, `healthcore-starter-pharmacy-commerce`
- **Strictly Excluded**: EMR, LIS, inpatient ADT, surgery/OT, mortuary, pharmaceutical manufacturing
- **Liquibase Master**: `classpath:db/changelog/packs/pack-pharmacy-master.xml`
- **Integration Guide**: `docs/integrations/PACK_01_PHARMACY_INTEGRATION_GUIDE.md`
- **Standalone Example**: `examples/standalone-pharmacy`
